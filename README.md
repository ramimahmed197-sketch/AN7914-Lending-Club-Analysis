# AN7914 Data Analytics and Modelling
## Determinants of Interest Rates in the Consumer Credit Market

**University of Winchester | Dr Sakib Anwar | May 2026**

## Project Overview
This project analyses the determinants of interest rates in the consumer 
credit market using the Lending Club dataset (10,000 loans).

## Dataset
- File: `loans_dataset.csv`
- Observations: 10,000 loans
- Source: Lending Club peer-to-peer lending platform

## Files
- `- `AN7914_analysi.py` — Main Python analysis script

## How to Run
1. Go to https://python-playground.com
2. Upload `loans_dataset.csv`
3. Paste the code from `AN7914_analysis.py` into main.py
4. Click Run

## Libraries Used
- pandas, numpy, matplotlib, scipy, statsmodels

## Analysis Structure
- Part A: Data Preparation
- Part B: Exploratory Data Analysis (EDA)
- Part C: Regression Analysis (5 models)
- Part D: Critical Discussion
